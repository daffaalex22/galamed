# Panduan CMS Galamed (untuk Back Office)

Buka: **https://galamed.vercel.app/admin** → **Login with GitHub**
(pakai akun GitHub kamu, minta akses repo dulu ke admin.)

## Tambah / ubah produk (1× seminggu, ±10 menit)

1. Buka **Produk** → **New Produk** (atau klik produk yang mau diubah).
2. Isi:
   - **Nama Produk**: cth: `Alcohol Swab Dus 100`
   - **Ringkasan Pendek**: 1 baris
   - **Deskripsi**: 1–2 kalimat
   - **Kategori**: pilih dari dropdown (jangan ketik bebas)
   - **Foto Produk**: klik upload, pilih JPG/PNG dari HP/laptop
3. Klik **Publish** → **Publish now**.
4. Tunggu ±2 menit (Vercel build otomatis) → cek halaman utama, produk sudah tayang.

## Ubah kontak (WA / email)

1. Buka **Pengaturan Situs** → **Kontak & Info**.
2. **No. WA Sistem** wajib format: angka saja diawali `62`, tanpa `+`, spasi, strip.
   Benar: `6282315822926` · Salah: `+62 823-1582-2926`
3. Publish → tunggu ±2 menit → tes tombol WhatsApp.

## JANGAN

- ❌ Rename / hapus file produk yang sudah ada (bikin link rusak).
- ❌ Upload foto di atas 2 MB (situs jadi lemot), crop dulu di HP.
- ❌ Ubah-ubah yang tidak dimengerti, tanya admin dulu.

## Kalau error

- Tidak bisa login → pastikan sudah accept invite collaborator GitHub (cek email).
- Publish tapi web tidak berubah > 10 menit → kabari admin (sertakan screenshot).
